# Icons
Icons can be inserted directly into the text of a note, taken from any icon pack installed in Trilium. An icon sits in the line like a character: it takes the colour and the size of the text around it, and it travels with that text when it is copied, exported or shared.

## Inserting an icon

*   In the <a class="reference-link" href="Formatting%20toolbar.md">Formatting toolbar</a>, go to “**Insert**” → “**Insert icon**”.
*   Alternatively, type `/icon` (or `/symbol`, or `/glyph`) and press <kbd>Enter</kbd>. See <a class="reference-link" href="Slash%20Commands.md">Slash Commands</a>.

Either way, the icon picker opens next to the cursor and shows every icon of every installed pack. Search for one by name, or use the selector to show a single pack, then click an icon to insert it. On a phone the picker opens as a dialog instead, since there is no room beside the cursor for it.

To have more icons to choose from, install another pack as described in <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Themes/Icon%20Packs.md">Icon Packs</a>.

## Changing the colour and the size

An icon takes the formatting of the text it sits in, so the usual controls apply to it:

*   Select the icon and use the text colour or the text background colour control to recolour it.
*   Use the font size control to make it larger or smaller. An icon inserted into text that is already enlarged arrives enlarged.

## Turning and mirroring an icon

Click an icon to select it, and a small toolbar appears above it. Press the “**Transform icon**” button to choose one of:

*   _No transform_, which is how an icon is inserted.
*   _Rotate 90°_, _Rotate 180°_ or _Rotate 270°_.
*   _Flip horizontally_ or _Flip vertically_.

Only one of these applies at a time, so choosing another replaces the one before it.

## Finding notes by their icons

An icon is part of a note's searchable text. A note carrying <span class="tn-icon bx bx-star"></span> is found by searching for `star`, the name of the icon, or for `bx-star`, the class it is drawn from.

Icons are also what the note tags of an imported OneNote page become — see <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Import%20%26%20Export/Importing%20data%20from%20other%20applications/Microsoft%20OneNote/Note%20Tags.md">Note Tags</a>.
